### Task 17: Implement /auth/verify/page.tsx
- Created `apps/web/src/app/(auth)/auth/verify/page.tsx` — client component completing the magic-link verification flow
- Three-stage state machine: `verifying` → `passkey-prompt` → redirect to `/` (or `error` if no session found)
- **Verifying stage**: reads session via `authClient.useSession()` hook from `better-auth/react`; waits up to 3 seconds for session to appear after magic-link redirect

- Passkey enrollment errors are silently swallowed (enrollment is optional) — redirects to `/` in the `finally` block regardless of success/failure
- Mirrors the Svelte verify page (`packages/web/src/routes/auth/verify/+page.svelte`) flow exactly, adapted for React/Next.js (useState, useEffect, useRouter, useSession hook)
